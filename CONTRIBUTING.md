# Участие в разработке

[← README](README.md)

Исправления детекторов, документации и новые адаптеры приветствуются.
Для ошибки укажите команду, версию Python, систему и ожидаемый результат.
Удалите личные данные из приложенных логов.

## Окружение

Из корня репозитория с активированным виртуальным окружением:

```bash
python -m pip install '.[dev]'
```

В Windows без активации используйте `.\.venv\Scripts\python.exe` вместо `python`.

## Проверки

```bash
python -m ruff check .
python -m ruff format --check .
python -m mypy --strict idlink tests tools
python -m pytest -q
```

При изменении нативного транспорта:

```bash
go vet ./native
go test -race ./native
```

Автоматические тесты используют синтетические фикстуры и MockTransport.
Реальные подключения и DNS запрещены autouse-фикстурой. В CI Python проверяется
на версиях 3.11–3.14, а Go-компонент — на Linux, macOS и Windows.

## Новый источник

1. Проверьте доступность публичного API или страницы и условия площадки.
2. Реализуйте адаптер с типизацией и docstring. Отсутствие профиля — `None`,
   ошибка доступа или сети — `PluginError`.
3. Используйте общий `PublicHTTP`, чтобы сохранить интервал и обработку отказов.
4. Добавьте фикстуры найденного и отсутствующего профиля, заглушки, блокировки
   и неоднозначного ответа. HTTP 200 без признаков профиля недостаточно.
5. Обновите каталог, происхождение правил и документацию. Выполните проверки выше.

Не добавляйте вход в аккаунты, обход CAPTCHA, утечки или сохранение текстов и картинок профилей.
Отчёт о найденном аккаунте и оценка связи между аккаунтами — отдельные результаты.

## Живой аудит

Живой аудит запускается вручную и выполняет реальные запросы, в отличие от тестов:

```bash
python -m tools.audit_catalog --live --username YOUR_USERNAME --out build/audit.json
python -m tools.render_catalog_audit build/audit.json --out docs
```

Результат отражает доступность на момент запуска. Неподтверждённая проверка не должна
переименовываться в «профиль отсутствует». В публикуемых материалах сохраняйте только
статусы и необходимые URL; исходные профили и изображения не прикладывайте.
