## Как выполняется поиск

Разные домены проверяются параллельно, до 256 работающих проверок.
Освободившийся слот сразу получает следующую площадку. Популярные источники
проверяются первыми; медленный сайт не задерживает всю группу.

Интервал между запросами к одному hostname по умолчанию — 2 секунды.
В `search` он настраивается: `--request-interval 0.5` (минимум 0,25 секунды).
Это не отменяет HTTP 403/429, Retry-After и ограничений площадок.
В режиме `--respect-robots` более строгий Crawl-delay также сохраняется.
Межпроцессный ограничитель не реализован: не запускайте параллельные копии для обхода лимита.

Сетевой таймаут — 6 секунд, включая DNS и загрузку ответа. Ожидание интервала
в него не входит. Общий бюджет проверки площадки — `4 × --timeout`, по умолчанию
24 секунды после получения рабочего слота. Он включает варианты регистра,
отрицательный контроль, очереди домена и robots.txt, если его проверка включена.
Ожидание свободного слота в этот бюджет не входит, поэтому весь поиск может идти дольше.
При исчерпании бюджета результат неизвестен; обязательная пауза не сокращается.

```bash
idlink search YOUR_USERNAME --timeout 12
idlink search YOUR_USERNAME --request-interval 0.5
idlink search YOUR_USERNAME --exact-case
```

Дополнительные варианты регистра проверяются только после подтверждённого отсутствия.
`--exact-case` отключает их. DNS и недоступность сервера ускорением интервала не исправить.

## Необязательный Go-транспорт

Python отвечает за CLI, адаптеры и скоринг; Go — за HTTP/TLS и проверку адреса
при соединении; JavaScript/D3 — за граф. Без Go приложение работает через httpx.

С Go 1.23+ соберите транспорт из корня проекта после создания `.venv`.

Linux / macOS:

```bash
go build -o .venv/bin/idlink-http ./native
```

Windows PowerShell:

```powershell
go build -o .venv\Scripts\idlink-http.exe ./native
```

Компонент обнаруживается автоматически рядом с Python виртуального окружения.

| `IDLINK_HTTP_ENGINE` | Транспорт |
|---|---|
| `auto` | Go при наличии, иначе httpx; значение по умолчанию |
| `go` | Обязательный Go-компонент |
| `python` | httpx |

Ответы передаются между процессами в памяти; исходные страницы в файлы не записываются.

## Замеры

Исторический тест на 384 сетевых фикстурах сравнил настройки 256/6 с предыдущими
128/20: 0,1214 с против 0,4526 с, или 3,73×. Половина источников не отвечала;
время было сжато в 100 раз, выполнено 3 повтора. Оба режима нашли 192 профиля
и отметили 192 источника как неопределённые. Это результат конкретного теста,
а не обещание ускорения реального поиска или сравнение со сторонними инструментами.

```bash
python -m tools.benchmark_pipeline
```

В больших графах индекс сигналов исключает пары, которые не могут достигнуть 30%
по текущим весам. Веб-интерфейс получает находки потоком и сохраняет позиции узлов.
