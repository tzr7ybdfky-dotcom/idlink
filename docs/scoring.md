# Оценка связей

[← README](../README.md)

```text
prior = 0.01
logit0 = ln(0.01 / 0.99)
posterior = sigmoid(logit0 + L_links + min(5.0, sum(other log_lr)))
```

| Сигнал | log_lr |
| --- | --- |
| Взаимные явные ссылки на адреса профилей | +6 |
| Односторонняя ссылка | +3 |
| pHash 64 бита: d ≤ 4; d 5–8; d ≥ 9 | +4; +1.5; 0 |
| Стандартный или отсутствующий аватар | 0 |
| Точный нормализованный ник; Jaro-Winkler ≥ 0.92 | +1 × rarity; +0.5 × rarity |
| Jaccard содержательных токенов ≥ 0.3 | +1 |
| Общий явный e-mail, домен или handle | +3 |
| ≥30 событий у обоих и cosine ≥0.9 | +0.5 |
| Преимущественно разные языки био | −1.5 |

Нормализация ника: lower, удалить `. _ -`; rarity = min(1, длина/12).
Для разных похожих имён используется меньшая длина — консервативный выбор.
Ник в списке частых у любого конца ребра подавляет вклад имени полностью.
Без положительного `links` результат дополнительно ограничен 85%.
При данной формуле лимит остальных сигналов фактически даёт максимум около 59.99% без links.
При prior=0.01 и весе +6 взаимные ссылки без других сигналов дают **80.30%**.
Взаимные ссылки вместе с дополнительными сигналами могут дать >85%.

Вердикты: <30% «связь маловероятна», 30–60% «возможна», >60% «вероятно связаны».
Веса не обучены на размеченных данных. Зависимые сигналы, шаблонное био, общий домен,
скопированная картинка, языки и автоматизация легко дают ложное сходство.
«Редкие токены» здесь — слова длиной ≥3 без стоп-слов ru/en и общих терминов;
это фильтр, а не измеренная частотность. «Уникальный идентификатор» тоже эвристика:
частые сервисные домены исключены, но персональность оставшихся не доказана.
Язык определяется по доминирующему алфавиту и может ошибаться у многоязычного человека.

`data/common_usernames.txt` содержит **45 вручную выбранных исключений**, включая `alex`.
Это **не top-10000**: достоверный разрешённый частотный источник не предоставлен.
Не используйте списки из утечек. Расширяйте файл проверенными открытыми данными;
копия `idlink/data/common_usernames.txt` входит в wheel, тест проверяет совпадение файлов.
