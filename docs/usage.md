# Руководство

[← README](../README.md)

## Команды

| Команда | Результат |
|---|---|
| `idlink search USERNAME` | Итоговый список найденных страниц |
| `idlink audit USERNAME --repository-url https://github.com/tzr7ybdfky-dotcom/idlink` | Проверка собственных профилей с HTML-отчётом |
| `idlink explain EDGE_ID --report report.html` | Разбор связи из сохранённого отчёта |
| `idlink help` | Команды и категории |

Запуск без имени команды (`idlink USERNAME`) использует `audit`.
У `audit` выбор площадок по умолчанию — `auto`: GitHub для ника, website для домена,
Gravatar для почты/хеша. У `search` — `all`.

## Типы ввода

```bash
idlink search USERNAME
idlink search example.org
idlink search user@example.org
```

- **Ник:** подходящие площадки каталога.
- **Домен:** публичная стартовая страница, meta description и ссылки `rel=me`.
- **Почта / хеш:** доступный аватар Gravatar. Почта нормализуется и хешируется;
  поиск регистрации этой почты на других сайтах не выполняется.

Явный публичный профиль можно добавить через `--profile` в `search` или `audit`:

```bash
idlink audit example.org --profile github:YOUR_USERNAME --repository-url https://github.com/tzr7ybdfky-dotcom/idlink --out report.html
```

## Отчёты

```bash
idlink search YOUR_USERNAME --out report.html
idlink explain EDGE_ID --report report.html
```

`search` без `--out` печатает только найденные ссылки и предупреждение перед поиском.
Ошибки отдельных площадок и сводные счётчики скрыты; статус завершения сохраняется.
С `--out` дополнительно печатаются предупреждения, ID связей и путь к отчёту.

В `report.html` встроены D3 7.9.0, стили и данные. Внешние скрипты, картинки,
шрифты и CDN не нужны; CSP запрещает сетевые обращения. `explain` читает этот файл
без выполнения JavaScript. Новый поиск выполняется через CLI.

Толщина ребра — `12 × probability`. Нажатие показывает причины и контрдоводы.
При более чем 24 узлах показываются только связи с оценкой ≥30%; узлы и статусы
сохраняются. Пунктир означает группировку наблюдений, а не оценку принадлежности.
Связи A↔B и B↔C не доказывают связь A↔C.

[Демонстрационный HTML](../examples/demo.html) содержит только синтетические профили.
Скачайте файл и откройте его в браузере.

## Коды выхода

| Код | Значение |
|---|---|
| `0` | Проверка завершилась успешно |
| `2` | Ошибка ввода или записи результата |
| `3` | Сетевая ошибка или запрет доступа хотя бы у части источников |

Код `3` возможен вместе с полезными находками. Он не означает, что все проверки провалились.

## Частые проблемы

**`Neither setup.py nor pyproject.toml found`** — установка запущена вне корня проекта.
Перейдите в папку, где находится `pyproject.toml`, и повторите установку.

**`destination path 'idlink' already exists`** — папка уже существует.
Если это ваша копия проекта, перейдите в неё; повторное клонирование не требуется.

**`idlink: command not found`** — активируйте окружение либо вызовите исполняемый файл напрямую:

```bash
.venv/bin/idlink search YOUR_USERNAME
```

В PowerShell: `.\.venv\Scripts\idlink.exe search YOUR_USERNAME`.

**`Authentication failed` при клонировании** — для приватного репозитория нужен доступ
к GitHub и настроенная Git-аутентификация. Обычный пароль GitHub для HTTPS Git не подходит.

**Результаты отличаются между запусками** — таймауты, DNS, блокировки и изменения сайтов
влияют на доступность. Сохраните HTML для просмотра статусов; при медленной сети
попробуйте `--timeout 12`. Ни ошибка, ни таймаут не доказывают отсутствие аккаунта.
